Shelf Life — Privacy Policy

Last updated: August 2026

Shelf Life is a Chrome extension that reads a user's own Steam library to predict "boredom risk" and expected playtime before buying a new game. This page explains exactly what data it reads, what (if anything) leaves your device, and why.

Data read locally (never leaves your device)

When you open your own Steam games/wishlist page, Shelf Life reads the page content already visible to you: game titles, Steam app IDs, hours played, and achievements. This is stored only in your browser's local extension storage (chrome.storage.local). Any manual tags you add are also stored only locally and are never shared.

Data shared with the community server (opt-out, on by default)

To power community-driven recommendations, Shelf Life can share a small, anonymized slice of your library with a small server the developer operates. This is on by default and can be turned off at any time from the Library tab in the extension popup — everything personal keeps working with it off.

What is sent, per game in your library:

  • Steam app ID
  • Hours played
  • Achievements unlocked / total
  • A coarse genre (e.g. "RPG", "Strategy"), auto-fetched from Steam's own public catalog
What is never sent: your Steam ID, username, profile information, which specific games you own beyond the list above, your manual tags, or anything else that could identify you.

How anonymization works

Your device is identified only by a random ID generated once, locally, on your own machine. Before this ID ever reaches the server, it is combined with a secret salt and cryptographically hashed. This means the server — and the developer — cannot connect a submission back to a specific Steam account, browser, or person.

Where data is processed and stored

Submitted data is processed by a Cloudflare Worker and stored in a Cloudflare D1 database, both operated directly by the developer. No data is sold, rented, or transferred to any third party. Cloudflare acts only as infrastructure/hosting for the developer's own server, the same way any web host does.

The server only ever publishes back aggregated statistics — medians, drop-off rates, and which games tend to be favorited together across many anonymous submissions — never any individual person's raw data.

Why data is collected at all

Community features (recommendations based on what similar players enjoyed, broadly well-regarded games, etc.) only work if there is data from more than one person. Sharing is on by default so these features can function from the start, but it is fully optional and easy to turn off.

Data retention and deletion

Because submissions are not linked to any identifying information, there is no way for the developer to look up or delete "your" specific data on request — the anonymization is designed to make that link impossible in the first place, not just hidden. Turning off sharing stops any future submissions immediately; it does not retroactively remove data already submitted, since that data cannot be distinguished from anyone else's.

No AI, no ads, no monetization

Shelf Life uses deterministic, rule-based scoring — no machine learning, no profiling beyond what's described above. It is a non-commercial hobby project: no ads, no accounts, and no plans to monetize it, ever.
